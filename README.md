# Portfolio

This is my personal portfolio website.

## Deployment

This static website is deployed using GitHub Pages.

### Steps to Deploy:

1. Ensure your code is committed and pushed to the main branch of your GitHub repository.

2. Go to your repository on GitHub.

3. Click on "Settings" tab.

4. Scroll down to "Pages" section.

5. Under "Source", select "Deploy from a branch".

6. Select "main" as the branch.

7. Click "Save".

8. Your site will be available at `https://<username>.github.io/<repository-name>/` (replace with your GitHub username and repository name).

If this is your user site (repository named `<username>.github.io`), it will be at `https://<username>.github.io/`.

### Local Development

Open `index.html` in your browser to view the site locally.
